# خارطة تطوير شاملة (بدون كسر الوظائف الحالية)

## مبادئ التنفيذ
1. الحفاظ على نفس منطق النظام الحالي.
2. التنفيذ على مراحل صغيرة قابلة للرجوع (rollback).
3. اختبار كل مرحلة قبل الانتقال للمرحلة التالية.

## المراحل
### المرحلة A: الأساس البصري (منجزة في هذا التحديث)
- Design Tokens مركزية.
- مكونات موحدة (Buttons/Cards/Tables/Forms/Alerts).
- ربط الثيمات الحالية (Panel + Admin) مع هوية Glass/Galaxy/Dark.

### المرحلة B: Profile / Settings
- إضافة صفحة إعدادات مستخدم متكاملة:
  - تعديل الاسم والصورة وكلمة المرور.
  - ملخص مالي (إيداع/صرف/رصيد).
- API endpoints آمنة للتحديث مع تحقق صارم.

### المرحلة C: Notifications
- جداول قاعدة بيانات للإشعارات.
- واجهة جرس إشعارات + حالات read/unread.
- لوحة Admin لإرسال الإشعارات.

### المرحلة D: i18n + RTL/LTR
- توحيد مفاتيح اللغة لكل الواجهات.
- تغطية عربية/إنجليزية كاملة.
- اختبار بصري كامل عند تبديل الاتجاه.

### المرحلة E: Currency Layer
- اعتماد EGP افتراضيًا.
- طبقة تنسيق عملات قابلة للتوسعة.

### المرحلة F: Bootstrap Conflict Removal
- صفحة-صفحة:
  1) neworder
  2) orders
  3) addfunds
  4) tickets
  5) admin reports/settings
- إزالة styles المكررة وinline styles تدريجيًا.

## معايير القبول
- لا توجد أخطاء PHP أو تعطّل في الصفحات الأساسية.
- توافق موبايل/تابلت/ديسكتوب.
- Contrast مقبول في dark mode.
