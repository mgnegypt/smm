# SMM Panel - تشغيل المشروع على الاستضافة (بشكل بسيط)

## المتطلبات
- PHP 8.0 أو أحدث
- MySQL / MariaDB
- Apache أو Nginx
- تفعيل الإضافات الشائعة في PHP مثل: `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `curl`, `json`

## خطوات الرفع والتشغيل
1. ارفع ملفات المشروع إلى مجلد الاستضافة (مثل `public_html`).
2. أنشئ قاعدة بيانات جديدة من لوحة الاستضافة.
3. استورد ملف قاعدة البيانات (إن كان متوفرًا مع المشروع).
4. إذا كان المشروع مرفوعًا مسبقًا، نفّذ ملفات التحديث التالية بالترتيب:
   - `updates/2026_03_16_add_profile_fields.sql`
   - `updates/2026_03_16_add_notifications_read_fields.sql`
5. عدّل بيانات الاتصال بقاعدة البيانات داخل ملفات إعدادات المشروع حسب بيئتك.
6. تأكد من صلاحيات الكتابة للمجلدات التي تحتاج رفع/تخزين ملفات (مثل `img/avatars/` أو مجلدات الكاش إن وجدت).
7. افتح الدومين في المتصفح وتأكد أن الصفحة الرئيسية تعمل.
8. اختبر تسجيل الدخول، الطلبات، والدفع للتأكد من سلامة التشغيل.

## ملاحظات مهمة
- المشروع تم تحسينه ليتوافق بشكل أفضل مع PHP 8 في نقاط الإدخال والدفع والمصادقة.
- إذا ظهر خطأ 500، راجع سجل الأخطاء من لوحة الاستضافة أولاً.
- يُفضّل تفعيل HTTPS قبل استقبال المدفوعات الفعلية.
